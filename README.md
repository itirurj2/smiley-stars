# Смайлик и Звёзды

Неоновая аркада в браузере. Собери огоньки, переверни роли и охоться на звёзд: 9 уровней, боссы, скины, кооп на одном устройстве и игра по сети.

## Как устроено

- `index.html` — вся игра, одним файлом. Публикуется через GitHub Pages.
- `server/` — сервер комнат на Node.js (WebSocket). Хранит комнаты и пересылает данные между игроками; сама игра считается в браузере хозяина комнаты.
- `render.yaml` — настройка для бесплатного хостинга Render.

## Игра по сети

1. Первый игрок: «Играть по сети» → «Создать комнату», отправляет другу ссылку или код.
2. Второй игрок открывает ссылку или вводит код.

Бесплатный сервер на Render засыпает, если им 15 минут никто не пользуется. Первое подключение после этого занимает до минуты.

## Запустить сервер у себя

```
cd server
npm install
npm start
```

Затем в `index.html` поменяй `SERVER_URL` на `ws://localhost:8080`.
