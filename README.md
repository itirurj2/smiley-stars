# Смайлик и Звёзды

Неоновая аркада в браузере. Собери огоньки, переверни роли и охоться на звёзд: 9 уровней, боссы, скины, кооп на одном устройстве и игра по сети.

## Битва шариков

`arena.html` — вторая игра, тоже одним файлом. Два простых шарика сами летают по маленькой квадратной арене и дерутся. Ими никто не управляет: стреляют и бьют они прямо туда, куда летят. Перед боем каждому шарику выбирают от одной до трёх способностей из 77. Среди них ледяные шипы, скелеты, оглушение, оружие, стрельба, стихии, призыв, защита и хитрости, а ещё 12 способностей из аниме (Расенган, Камехамеха, Остановка времени, Тетрадь смерти…) и 13 из Доты (Гниль, Хроносфера, Омнислэш, Палец смерти…). Если бой затянулся, на 50-й секунде стены раскаляются и обжигают каждого, кто от них отскакивает.

Цифры способностей подобраны по тысячам боёв без графики: против всех остальных вместе каждая способность выигрывает от 39 до 58% боёв. Отдельные пары могут быть неравными, например зеркало против стрелков. Перепроверить баланс можно на локальном сервере, в консоли браузера: `__arena.bench(4)`.

## Стальные схемы

`scheme.html` — редактор блок-схем на поле из шлифованной стали, тоже одним файлом. Фигуры как в draw.io: основные и все фигуры блок-схем, стрелки трёх форм (ломаная, прямая, кривая) с разными наконечниками и подписями. «Текст» в списке фигур — прозрачная табличка: на ней можно писать прямо на поле. Размер фигур меняется белыми квадратами, текст пишется двойным кликом. Кнопка «Запустить» прорисовывает готовую схему паяльником: искры бегут по контурам, след остывает, текст выжигается.

Схемы сохраняются в браузере («Файл» → «Мои и готовые схемы»), а ещё в файл `.json`, в PNG и SVG.

### Готовые схемы

Папка `schemes/` — схемы, которые видны на сайте в разделе «Готовые схемы». Чтобы добавить схему, положи файл в папку и допиши его в `schemes/index.json`. Ссылка `scheme.html?scheme=имя-файла` открывает схему сразу.

Формат файла:

```json
{
  "title": "Название",
  "shapes": [
    { "id": "a", "type": "terminator", "x": 0, "y": 0, "w": 140, "h": 50, "text": "Начало" },
    { "id": "b", "type": "rhombus", "x": -20, "y": 100, "w": 180, "h": 100, "text": "Условие?" }
  ],
  "edges": [
    { "id": "e1", "from": "a", "to": "b", "label": "Да" }
  ]
}
```

- `type` фигуры: `text`, `rect`, `rounded`, `ellipse`, `rhombus`, `triangle`, `hexagon`, `parallelogram`, `trapezoid`, `cylinder`, `cloud`, `note`, `callout`, `blockArrow`, `actor`, `terminator`, `predefined`, `document`, `multidoc`, `manualInput`, `manualOp`, `internalStorage`, `storedData`, `delay`, `display`, `card`, `tape`, `offpage`, `loopLimit`, `or`, `sumJunction`, `merge`, `sort`, `annotation`.
- Необязательный вид фигуры: `fill` (цвет, `none`, `chrome`, `copper`, `plate`), `stroke`, `width`, `dash` (`solid`, `dash`, `dot`), `fontSize`, `color`, `bold`, `italic`, `align`, `shadow`.
- Стрелка: `from` и `to` — id фигур, или свободные концы `x1`, `y1`, `x2`, `y2`. Сторону можно задать через `fromPort` и `toPort` (`top`, `right`, `bottom`, `left`), иначе она выбирается сама. Ещё есть `route` (`orthogonal`, `straight`, `curved`), `startArrow` и `endArrow` (`none`, `arrow`, `open`, `triangle`, `diamond`, `diamondOpen`, `circle`, `circleOpen`, `erOne`, `erMany`), `label`, `stroke`, `width`, `dash`, `bend` — точка изгиба.

### Чат

Окно чата уже есть, но пока не подключено к ИИ. Когда будет сервер, его адрес вписывается в настройках чата. Сервер получает `POST` с `{ "message", "history", "diagram" }` и отвечает `{ "reply": "текст", "diagram": { ...схема... } }`; схема в ответе необязательна и применяется кнопкой. Ключ ИИ хранится только на сервере, в страницу его не кладём.

## Как устроено

- `index.html` — вся игра «Смайлик и Звёзды», одним файлом. Публикуется через GitHub Pages.
- `arena.html` — «Битва шариков», тоже одним файлом. Ссылка на неё есть в главном меню.
- `scheme.html` — «Стальные схемы», редактор блок-схем. `schemes/` — готовые схемы для него.
- `server/` — сервер комнат на Node.js (WebSocket). Хранит комнаты и пересылает данные между игроками; сама игра считается в браузере хозяина комнаты.
- `render.yaml` — настройка для бесплатного хостинга Render.

## Игра по сети

1. Первый игрок: «Играть по сети» → «Создать комнату», отправляет другу ссылку или код.
2. Второй игрок открывает ссылку или вводит код.

Бесплатный сервер на Render засыпает, если им 15 минут никто не пользуется. Первое подключение после этого занимает до минуты.

## Запустить сервер у себя

```
cd server
npm install
npm start
```

Затем в `index.html` поменяй `SERVER_URL` на `ws://localhost:8080`.
