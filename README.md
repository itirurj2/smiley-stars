# Смайлик и Звёзды

Неоновая аркада в браузере. Собери огоньки, переверни роли и охоться на звёзд: 9 уровней, боссы, скины, кооп на одном устройстве и игра по сети.

## Битва шариков

`arena.html` — вторая игра, тоже одним файлом. Два простых шарика сами летают по маленькой квадратной арене и дерутся. Ими никто не управляет: стреляют и бьют они прямо туда, куда летят. Перед боем каждому шарику выбирают от одной до трёх способностей из 77. Среди них ледяные шипы, скелеты, оглушение, оружие, стрельба, стихии, призыв, защита и хитрости, а ещё 12 способностей из аниме (Расенган, Камехамеха, Остановка времени, Тетрадь смерти…) и 13 из Доты (Гниль, Хроносфера, Омнислэш, Палец смерти…). Если бой затянулся, на 50-й секунде стены раскаляются и обжигают каждого, кто от них отскакивает.

Цифры способностей подобраны по тысячам боёв без графики: против всех остальных вместе каждая способность выигрывает от 40 до 61% боёв. Отдельные пары могут быть неравными, например зеркало против стрелков. Перепроверить баланс можно на локальном сервере, в консоли браузера: `__arena.bench(4)`.

## Как устроено

- `index.html` — вся игра «Смайлик и Звёзды», одним файлом. Публикуется через GitHub Pages.
- `arena.html` — «Битва шариков», тоже одним файлом. Ссылка на неё есть в главном меню.
- `server/` — сервер комнат на Node.js (WebSocket). Хранит комнаты и пересылает данные между игроками; сама игра считается в браузере хозяина комнаты.
- `render.yaml` — настройка для бесплатного хостинга Render.

## Игра по сети

1. Первый игрок: «Играть по сети» → «Создать комнату», отправляет другу ссылку или код.
2. Второй игрок открывает ссылку или вводит код.

Бесплатный сервер на Render засыпает, если им 15 минут никто не пользуется. Первое подключение после этого занимает до минуты.

## Запустить сервер у себя

```
cd server
npm install
npm start
```

Затем в `index.html` поменяй `SERVER_URL` на `ws://localhost:8080`.
